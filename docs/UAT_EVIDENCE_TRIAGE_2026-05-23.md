#### M2 — CSV exports leak display formatting into data → **FIXED 2026-05-24**

Streamlit's `st.dataframe` auto-CSV-download captures whatever DataFrame is passed in. Multiple pages were mutating numeric columns into formatted strings (e.g. `"$313,012,000"`) before passing to `st.dataframe`, so the CSV download got strings.

**Pattern used for every fix:** keep the DataFrame numeric; format at display only via `st.column_config.NumberColumn(format=...)`. Percent values converted from fractions to percent-numerics (e.g. `0.30` → `30.0`) so CSV consumers can parse them as numbers.

#### M3 — Quarantine records lack populated `failing_field` / `failing_value` → **FIXED 2026-05-24**

- **Fix applied:** [src/data_quality/runner.py](src/data_quality/runner.py) — `_insert_quarantine_records` now populates:
  - `failing_field` — extracted via a new `_extract_failing_field()` helper that finds the first snake_case (or mixed-case-with-underscore) identifier in the check description. Falls back to `check_id` if no identifier matches.

- **Limitation noted in code comment:** True per-policy field values would require extending the check return type across all per-product check modules — out of scope for this fix. Current approach gives auditors a much better handle on the audit trail than NaN.
